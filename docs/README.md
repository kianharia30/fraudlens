# docs/

- `MODEL_CARD.md`: model card (results filled by `make readme`).
- `metrics.json`: every reported number, written by `make train` (committed).
- `benchmark.json`: API latency, written by `make benchmark` (committed).
- `DATA_REPORT.md`: dropped columns and encodings, written by `make train`.
- `figures/`: PR, ROC, calibration, feature importance and score distribution (test block).
